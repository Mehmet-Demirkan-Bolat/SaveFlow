SQLite JDBC Sürücüsü Kurulum Talimatları
==========================================

Bu klasöre sqlite-jdbc-3.xx.x.jar dosyasını indirip koymanız gerekmektedir.

İndirme adresi:
  https://github.com/xerial/sqlite-jdbc/releases/latest
  (sqlite-jdbc-3.45.3.0.jar veya daha yeni bir sürüm)

İndirdikten sonra dosyayı "sqlite-jdbc.jar" olarak bu klasöre kaydedin.
(lib/sqlite-jdbc.jar)

Eclipse'de projeyi yeniden açtığınızda Build Path otomatik algılar.
E�er algılamazsa: Projeye sağ tıkla → Build Path → Configure Build Path
→ Libraries → Add JARs → lib/sqlite-jdbc.jar seçin.
